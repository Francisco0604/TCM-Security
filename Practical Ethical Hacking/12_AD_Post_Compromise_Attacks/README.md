# 📁 Attacking Active Directory: Post-Compromise Attacks 

> **Curriculum:** TCM Security — Practical Ethical Hacking (PEH)  
> **Module Description:** Pass-the-Hash, Pass-the-Password, Token Impersonation (Incognito), Kerberoasting (T1558.003), LNK file attacks, GPP / cPassword, and Mimikatz credential dumping.

---

## 🎯 Module Overview & Learning Outcomes
This module provides practical, hands-on methodology and field-tested offensive techniques for **Attacking Active Directory: Post-Compromise Attacks **. 

### 🛠️ Key Tools & Technologies Used
- Specialized exploitation, scanning, and enumeration toolkits.
- Command-line syntax, packet captures, and proof-of-concept demonstrations.
- Defensive detection signatures and hardening strategies.
