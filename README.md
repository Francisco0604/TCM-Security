# TCM Security - Course Notes & Lab Walkthroughs

Personal study notes, practical lab walkthroughs, commands, and machine write-ups from TCM Security courses.

> **Note on Documentation Progression:**  
> Earlier modules reflect earlier stages of learning and practical note-taking, and are being progressively revised to current documentation standards.

---

## Courses Covered

- 🛡️ [**Practical Ethical Hacking (PEH)**](./Practical%20Ethical%20Hacking/README.md)  
  *Networking, OSINT, Nmap scanning, Active Directory attacks (LLMNR, SMB Relay, Kerberoasting, Mimikatz, DCSync), Web vulnerabilities (SQLi, XSS, File Upload), Wireless pentesting, and Capstone machines (Blue, Academy, Dev, Butler, Blackpearl).*

- 🐧 [**Linux Privilege Escalation**](./Linux%20Privilege%20Escalation/README.md)  
  *System enumeration, Kernel exploits, Sudo misconfigurations (LD_PRELOAD, GTFOBins), SUID binaries, POSIX capabilities, Cron wildcards, NFS no_root_squash, Docker escapes, and Capstone machines (LazyAdmin, Anonymous, Tomghost).*
