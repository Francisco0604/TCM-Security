# 📁 5 Stages of Ethical Hacking

> **Curriculum:** TCM Security — Practical Ethical Hacking (PEH)  
> **Module Description:** Industry standard penetration testing lifecycle: Reconnaissance, Scanning & Enumeration, Gaining Access, Maintaining Access, and Covering Tracks.

---

## 🎯 Module Overview & Learning Outcomes
This module provides practical, hands-on methodology and field-tested offensive techniques for **5 Stages of Ethical Hacking**. 

### 🛠️ Key Tools & Technologies Used
- Specialized exploitation, scanning, and enumeration toolkits.
- Command-line syntax, packet captures, and proof-of-concept demonstrations.
- Defensive detection signatures and hardening strategies.
